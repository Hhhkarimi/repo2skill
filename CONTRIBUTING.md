# Contributing

1. Fork the repository and create a focused branch.
2. Keep analysis deterministic and evidence-backed; do not add a paid AI dependency to the default path.
3. Add new stack detectors conservatively and avoid claiming behavior that cannot be inferred from repository evidence.
4. Keep all seven dictionaries structurally identical when adding user-facing copy.
5. Run `npm run check` before opening a pull request.
6. Preserve the untrusted-repository-content boundary in generated Skills.
